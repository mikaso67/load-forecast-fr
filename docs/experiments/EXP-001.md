The optional dbt bound applies before deduplication and defaults to no bound for other builds. The script uses this parameterized query with start=2023-12-24 23:00 UTC and end=2024-12-31 23:00 UTC:

The SQL below is a `clean_query` template: `{table}` is the relation selected by `LFF_CLEAN_TABLE`. The recorded output came from a development build of the clean model `load_30min`.

```sql
SELECT value_time, consommation, prevision_j1, source_dataset
FROM {table}
WHERE value_time >= %(start)s AND value_time < %(end)s
ORDER BY value_time
```

Limitations: D2 is a proxy because raw data lacks per-value publication timestamps.
