Tomorrow's French electricity demand, forecast every day at noon.

Every day before 12:00 Paris time, my model forecasts France's national electricity consumption for the next day, half-hour by half-hour, and compares it with the official day-ahead forecast of RTE, the French grid operator. Collection, forecasting, scoring and publication run automatically.

Live forecasts start on 15 October 2026. Earlier days are a replay: the same production code run on past data, not forecasts published in advance.

How it works

  1. Collect

    RTE eCO2mix consumption every 30 minutes, NOAA GFS weather forecasts.

  2. Freeze at noon

    Only data available before 12:00 the day before is used.

  3. Forecast

    Four models: linear regression, two GAMs one with a Kalman filter, LightGBM, combined by online aggregation. An 80 percent interval by conformal prediction.

  4. Monitor

    Daily scoring, a CUSUM drift alarm, weekly retraining.
